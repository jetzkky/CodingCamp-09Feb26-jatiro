## Jetzkky Global Corporation

A responsive company profile website developed as part of the Mini Coding Camp project.

## 📌 Project Overview

Jetzkky Global Corporation is a fictional digital agency focused on empowering SMEs (Small and Medium Enterprises) through strategic digital growth solutions.  

This website demonstrates fundamental front-end development skills including HTML structure, CSS styling, JavaScript DOM manipulation, and form validation.

---

## 🎯 Features

- Responsive layout (Desktop & Mobile)
- Navigation menu with section linking
- Dynamic welcome message using JavaScript
- Company profile section (About, Vision, Mission)
- Portfolio section
- Message form with validation:
  - Required field validation
  - Email format validation (Regex)
  - Phone number numeric validation
  - Display submitted data dynamically on the page

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Git & GitHub
